# Color & Theme Reference Guide

## 🎨 Complete Color Palette

### Primary Colors (Beach Theme)
```
Cyan Blue      #0EA5E9  - Fresh ocean water, primary buttons
Teal           #06B6D4  - Deeper ocean, button hovers
Turquoise      #14B8A6  - Tropical lagoons
```

### Accent Colors (Cuban Theme)
```
Orange         #F97316  - Warm Cuban sunset, secondary buttons
Gold           #FCD34D  - Dealer chips, luxury accents
Lime Green     #84CC16  - Messages button, tropical plants
```

### Supporting Colors
```
White          #FFFFFF  - Text, backgrounds
Light Gray     #E2E8F0  - Form borders
Dark Slate     #1E293B  - Primary text
Cool Gray      #64748B  - Secondary text
Sky Light      #F0F9FF  - Focus state backgrounds
```

## 🌊 Gradient Combinations

### Main Background
```
linear-gradient(135deg, #0EA5E9 0%, #06B6D4 50%, #14B8A6 100%)
```
Creates a beautiful flow from ocean blue to turquoise

### Game Container
```
linear-gradient(135deg, rgba(255,255,255,0.95) 0%, rgba(240,249,255,0.98) 100%)
```
Subtle white-to-light-blue for clean interface

### Title Gradient
```
linear-gradient(135deg, #0EA5E9 0%, #F97316 100%)
```
Blue to orange gradient for eye-catching header

### Game Link Display
```
linear-gradient(135deg, rgba(14,165,233,0.08) 0%, rgba(20,184,166,0.08) 100%)
```
Subtle teal gradient for secondary containers

## 📱 Font Selection

### Modern, Friendly Fonts
- **Fredoka** (Regular, 400-700 weight)
  - Primary font for UI
  - Rounded, approachable feel
  - Used for labels, buttons, body text

- **Poppins** (600-700 weight)
  - Titles and headers
  - Bold, confident appearance
  - Used for main heading

- **Arial/System** (Game board only)
  - Game status and card text
  - High legibility
  - Monospace alternative for prices/numbers

## 📐 Spacing & Layout

### Padding Standards
```
Large:   40px  - Main container
Medium:  20px  - Cards, panels
Small:   12px  - Buttons, inputs
Tiny:    8px   - Text padding
```

### Gap Standards
```
Large:   20px  - Between sections
Medium:  18px  - Form fields
Small:   12px  - Button groups
Tiny:    8px   - Inline items
```
